# 默认智能区域与就地编辑

2026-10-15。范围仅为 jiamiing/papero，沿用当前 GitHub Pages 路径，不改其他仓库、账号设置或主页。

主要流程：点照片 → 自动识别完整区域 → 选区旁出现「颜色 / 文字 / 素材」→ 立即预览。没有「选得不太对」这一步。点其他位置切换目标；收起按钮退出选区，后续再点照片仍为智能选择。

默认分割使用 SlimSAM q8 / WASM，在独立 Worker 内运行。打开照片即预热，工作分辨率最长边 900px；同张照片复用编码特征，串行处理推理并合并等待中的点击。照片与请求编号都校验，旧结果不能覆盖新照片或新点击。蒙版候选必须包含点击点；置信度接近时偏向完整区域，过滤近乎全图的无效候选。后处理闭合细裂缝、保留点击所在的连通区域、去除游离碎片并填小孔；大孔洞保留。

边界改成首尾相连的轮廓，虚线不再每像素重启。填充缩放保留边缘透明度。轻微着色和轮廓动画尊重系统减少动态效果设置。

首次模型准备会在点选处显示进度。模型加载或推理失败时，自动使用清理后的颜色连通区域并明确提示，用户仍可直接编辑，无需调整参数。手动「圈一下」保留为补充。深度功能继续独立按需运行。

浮动编辑面板在宽屏尽量放在画布边上，窄屏保持在画布下部、工具行之上。它不阻塞其他照片区域的点击。颜色点击即生效；文字输入后可直接填进蒙版；素材可选择网点、双色、棋盘、杂志与八种原创素材拼贴填充。持续试色/文字/素材均复用同一个填充层，原始照片及其他文字贴纸图层保留。撤销/重做继续有效。

照片不上传。模型从 Hugging Face 下载，缓存由浏览器管理，首次加载速度及语义识别质量需要在不同设备和网络上继续实测。此版本已实际验证浏览器加载模型并对示例照片进行智能区域选择；未声称通过 iOS/Android 真机推理测试。
