# 从 MVP 到可发布应用

## 先验证编辑体验

- 真机矩阵：Safari / iPhone WKWebView / Android WebView / Chrome；记录端侧分割、深度的首次下载大小、峰值内存、耗时、失败率。
- AI 蒙版增减点、羽化/扩张/收缩、橡皮擦和画笔修补；大图分块与低内存模式。
- 手势双指缩放/旋转；目前图层通过单指移动和参数滑杆编辑。
- 模型版本固定到经过测试的 revision，显式展示下载总大小、存储占用与删除模型缓存入口。
- 首次图片仍以 1600px 最长边处理；发布前增加按输出需求选择 2K/4K 与内存预算。

## 视觉素材与手帐

- 使用有明确授权来源的真实照片剪贴素材，增补花、眼睛、雕塑、天空、植物、金属、纸边、胶带。
- 中文排版组合与字体授权清单；字体的英文字形先用 Bodoni Moda。
- 自定义纸张图片填充、蒙版材质位置/比例、混合模式、纸边描边、颗粒与复印机纹理。
- 多页手帐、模板、项目缩略图、搜索与可恢复删除；当前库可打开记录，尚无记录删除 UI。

## 深度再推进

- 深度驱动 WebGL 网格位移与遮挡修补；焦点、景深、立体阴影。
- 限制相机移动，导出带预览的短视频；检查编解码支持和授权。
- 有必要才增加云端生成：一个 Worker 网关，密钥不下发客户端。

## 发布前

- 替换原生项目默认启动图/图标，制作 Android adaptive icon 和各平台完整尺寸。
- Xcode / Android Studio 真机调试与 release build；开发者配置签名、Bundle ID 和商店账号。
- iOS 隐私 manifest、系统文件保存流程、Android scoped storage、无障碍与触屏回归。
- 数据丢失/缓存清理提示、隐私政策、许可证清单、模型源服务可用性策略。
- 工具链 CI 与依赖审计；当前工作流只自动验证网页类型检查、测试和构建。
