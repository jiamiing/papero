# 默认点选与色块编排

2026-10-15。只更新 Papero，不改变其他项目、域名、个人主页或账号设置。

主要路径：打开照片 → 点一处 → 点颜色/填充方式。无需先选工具，也无需二次点击应用。保持选区可以连续试色；再次点照片切换到新区域。所有替换均可撤销，原照片保留。

默认选择采用连通颜色区域，图片一次缩至最长边 900px 后交给独立 Worker；每次点击复用像素。输入图片保留最长边 1600px，导出沿用原项目尺寸。轻量描边和低透明度着色展示选区；尊重减少动态效果系统设置。请求编号和照片编号一起校验，丢弃过期计算结果。

修正入口在选中后出现：调整范围、圈一下、识别整个物体。SlimSAM 按需下载，在独立 Worker 中运行，同一张图片复用图像 embeddings。识别时仍可继续编辑，过期结果不覆盖新选区。深度功能保留。

新色块插在原照片之上、文字与贴纸之下。连续切换颜色/材质更新同一个填充层。新增纯色、自定义颜色、黑色网点、双色映射与重复无衬线文字。文字可在粗无衬线、等宽小字和斜体衬线之间切换。

旧手帐继续从本地加载；不会删除或自动改写旧作品的视觉内容。查看新设计可点「看新示例」。旧项目里没有 font 属性的文字继续使用原来的衬线样式。

视觉依据为用户提供的日韩 Y2K 海报与数码手帐参考。主要变化是明亮底色、强色块、文字大小对比与留白；生成素材作为小范围点缀。示例照片是内置 image_gen 工具生成的原创虚构成年人照片，不使用参考海报里的真实人物。
